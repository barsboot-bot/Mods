## 📋 Как правильно использовать приложение

### Шаг 1: Настройте структуру мода
- Откройте вкладку **"Структура мода"**
- Заполните информацию о проекте (название, автор, описание)
- Добавьте файлы и папки через дерево каталогов или кнопки быстрого добавления
- **Важно:** используйте выпадающий список "Куда добавить" для вставки файлов в нужные папки

### Шаг 2: Настройте конфиги
- Откройте вкладку **"Генератор конфигов"**
- Настройте параметры:
  - **mod.cpp** — название мода, директория, описание
  - **serverDZ.cfg** — настройки сервера (имя, пароль, макс. игроков и т.д.)
  - **types.xml** — спавн лута
  - **econ.xml** — экономика
  - **cfggameplay.json** — настройки геймплея

### Шаг 3: Добавьте скрипты (опционально)
- Откройте вкладку **"Библиотека скриптов"**
- Выберите готовый сниппет кода
- Нажмите **"Вставить в файл"** или **"Создать новый файл"**
- Код будет добавлен в ваш проект

### Шаг 4: Отредактируйте файлы (опционально)
- Во вкладке **"Структура мода"** кликните на файл в дереве
- Откроется редактор кода справа
- Отредактируйте содержимое и нажмите **"Сохранить"**

### Шаг 5: Экспортируйте проект
- Откройте вкладку **"Экспорт проекта"**
- **Автоматически** применятся ваши настройки из конфигов к файлам
- Проверьте **превью файлов** — убедитесь, что всё корректно
- Нажмите **"Применить все конфиги к файлам"** (если нужно явно применить)
- Нажмите **"Скачать ZIP"**

## 🎯 Ключевые особенности

### ✅ Вставка файлов в папки
- Используйте выпадающий список **"Куда добавить"** при добавлении файлов
- Или нажмите **"+"** на папке в дереве для добавления прямо в неё

### ✅ Редактор кода
- Кликните на файл в дереве — откроется редактор справа
- Редактируйте код и нажимайте **"Сохранить"**
- Изменения сохраняются в проекте

### ✅ Вставка скриптов из библиотеки
- В **"Библиотеке скриптов"** нажмите **"Вставить в файл"**
- Выберите существующий файл или создайте новый
- Код будет добавлен в проект

### ✅ Экспорт с вашими настройками
- При открытии вкладки **"Экспорт"** конфиги автоматически применяются
- Превью показывает, что попадёт в ZIP
- Кнопка **"Применить все конфиги"** для явного применения
